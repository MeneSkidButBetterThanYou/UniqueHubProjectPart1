## ◆ UNIQUE

**UNIQUE** is a Roblox Luau hub project focused on a runtime performance, compatibility, and experimenting with script protection.
This repository is also being used as a public testbed.

The code may be:

- inspected
- dumped at runtime
- deobfuscated
- reverse engineered
- benchmarked
- compared against different protection methods

If you find a weakness, that's useful information.

The goal isn't to pretend client-side code is impossible to recover.

The goal is to see **how much work recovery actually takes** while keeping the original script usable and fast.
